# 🐍 Python Learning Journey

Welcome to my Python learning journey!

This repository documents my progress as I learn Python from the ground up. It includes beginner exercises, small challenges, and mini projects developed while following the *100 Days of Code: The Complete Python Pro Bootcamp* course.

My goal is to build a solid foundation in programming, understand how things work behind the scenes, and gradually move toward more advanced Python development.
