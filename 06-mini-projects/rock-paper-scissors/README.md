# Rock Paper Scissors

A simple command-line Rock Paper Scissors game built with Python as part of my learning journey.

## How It Works

The player chooses Rock (0), Paper (1), or Scissors (2). The computer makes a random choice, and the program determines the winner.

## Concepts Practiced

- Random number generation with `random.randint()`
- Lists and indexing
- Conditional statements (`if`, `elif`, `else`)
- User input and type conversion
- Logical operators

## How to Run

```bash
python main.py
```
