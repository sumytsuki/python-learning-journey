# Blind Auction

A command-line blind auction program built with Python as part of my learning journey.

## How It Works

Participants enter their names and bids one at a time.

After each bid, the program asks whether another participant wants to bid. If so, the terminal is cleared visually using blank lines to help keep previous bids hidden.

When bidding ends, the program compares all submitted bids and announces the highest bidder.

- Dictionary iteration

## How to Run
