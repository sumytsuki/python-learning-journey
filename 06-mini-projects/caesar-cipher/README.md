# Caesar Cipher

A command-line encryption and decryption program built with Python as part of my learning journey.

## How It Works

The Caesar Cipher shifts each letter in a message by a specified number of positions in the alphabet.

The user can choose to encode or decode a message. The program preserves spaces, numbers, and punctuation.

For example, shifting `hello` forward by 5 positions produces `mjqqt`.
